# T-Mobile Polska Replica

## Project Overview
The T-Mobile Polska Replica is a frontend project that mimics the design and functionality of the T-Mobile Polska website. Utilizing modern web technologies like Tailwind CSS and Font Awesome, this project showcases a responsive layout and a cookie consent modal. It is primarily aimed at those wanting to understand how to build a clean, responsive web interface.

## Installation
To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/t-mobile-polska-replica.git
   ```

2. Navigate to the project directory:
   ```bash
   cd t-mobile-polska-replica
   ```

3. Open the `index.html` file in your web browser to view the project.

## Usage
The replica serves as a static website that visitors can interact with. Key sections include a navigation bar, a promotional hero section, and a cookie consent modal. Users can click buttons to simulate actions such as viewing a cart or accessing account information. 

### Features
- **Responsive Layout**: The design adapts to different screen sizes.
- **Cookie Consent Modal**: Users can accept cookies or manage their preferences.
- **Interactive Elements**: Buttons for user account access, cart viewing, and support.
- **Promotional Sections**: Attention-grabbing sales information.

## Dependencies
The project utilizes the following dependencies, which are loaded via CDNs in the `index.html`:

- **Tailwind CSS**: For styling and responsive design.
- **Google Fonts**: Specifically the "Inter" font family for a clean look.
- **Font Awesome**: For iconography.

## Project Structure
The Project is structured as follows:

```
/t-mobile-polska-replica
│
├── index.html            # The main HTML file for the project
```

### Key Sections in `index.html`:

- **Header**: Contains the T-Mobile logo and navigation buttons.
- **Black Banner**: Displays a promotional message.
- **Hero Section**: Welcomes users with a bold message and a prominent call to action.
- **Cookie Consent Modal**: Manages user consent for cookies with functional buttons.
